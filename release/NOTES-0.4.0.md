# Focus 0.4.0

Local screen time and hourly limits for Omarchy Linux: categories, schedules,
pauses, shared counters, seven-day history and local exports.

Follow the [installation guide](https://github.com/NoFlairos/focus#install).
The widget requires its Python helper and user service. The optional Chromium /
Chrome extension requires native-host registration; the ZIP is an unpacked build.

40 Python tests, browser tests, Qt integration and an isolated real Chromium/helper
check passed. Fresh Omarchy session testing remains outstanding; see
[validation](https://github.com/NoFlairos/focus/blob/main/release/VALIDATION.md).

Default limits close windows or active tabs. Covered windows may count; ambiguous
browser titles are skipped. Merged historical totals cannot be separated later.

Assets: source ZIP, extension ZIP and SHA256SUMS.
[Privacy](https://noflairos.github.io/focus/privacy.html).
