Local screen time and hourly limits for visible apps and websites, with schedules,
shared counters and a seven-day history view.

**Setup required:** install the Python helper and systemd user service before
using the widget. Website tracking also requires the extension and native-host
registration. See the [README](../README.md).

The plugin reads window metadata, stores local history/settings and can close
configured windows or active tabs at their limit. It can also send notifications,
restart its helper and export files on request. No remote tracking backend.

Previews: `assets/panel-manage.png`, `panel-now.png`, `bar-focus.png`.
